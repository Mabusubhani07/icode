# iCode scaffold

This branch contains a minimal scaffold for Phase 1:

- Next.js + TypeScript frontend skeleton
- TailwindCSS setup files
- Landing page (placeholder)
- Editor page (Monaco stub using a textarea and Run/Reset/Clear) that calls a stubbed API
- Stubbed API route: /api/run — returns canned output for now

To run locally:
1. Install Node.js LTS
2. npm install
3. npm run dev

Notes: This is a starting point. The real Monaco integration, linting, and CI are planned in the Phase 1 spike.
