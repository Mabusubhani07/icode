# iCode — Programming Mastery Engine (MVP)

A free platform for teaching programming deeply. Focused on C and C + DSA for the initial MVP. The goal is mastery — not just code or tutorials.

## Vision

Learn Code. Understand It. Break It. Debug It. Master It.

This repository contains the product and implementation work for the iCode platform.

## Phase 1 — Foundation (priority)

- Landing page
- Authentication
- Dashboard
- C course navigation
- Concept pages
- Progress tracking

## Quick tech recommendations (MVP)

- Frontend: Next.js + React, TailwindCSS for styling, Monaco Editor for code editing UI
- Backend: Node.js + TypeScript (Express/Nest) or Go for API
- Database: PostgreSQL for relational data, Redis for cache + job queue
- Code execution: Prototype with a stubbed UI; evaluate WebAssembly vs containerized server execution (see ARCHITECTURE.md)
- CI/CD: GitHub Actions
